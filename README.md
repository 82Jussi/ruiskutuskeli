# Ruiskutuskeli

GitHub Pages -yhteensopiva HTML/JavaScript-sovellus ruiskutuskelin arviointiin.

## Ominaisuudet

- Karttapisteen valinta Leaflet-kartalta
- Open-Meteo 72 h ennuste valittuun pisteeseen
- Tuuli muodossa m/s
- Sateen todennäköisyys prosentteina
- Ilmankosteus prosentteina
- Värikoodattu tuntitaulukko: vihreä, keltainen, punainen
- Automaattinen parhaan ruiskutusikkunan tunnistus
- Asetukset hammaspyörän takana oikeassa yläkulmassa
- Muokattavat pisterajat ja painokertoimet
- Suomalainen aikamuoto: pp.kk hh:mm, vuosi jätetty pois

## Käyttö GitHub Pagesissa

Lataa nämä tiedostot repositorion juureen:

- index.html
- style.css
- app.js
- manifest.json

Ota GitHub Pages käyttöön repositorion asetuksista: Settings > Pages > Deploy from branch > main > / root.
